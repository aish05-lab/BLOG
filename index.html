Study of Hash Function - RSHash

What is RSHash?

RSHash is a simple and fast hashing function developed by Robert Sedgwick. It uses two magic numbers (63689 and 378551) to generate a unique integer for any string.

How RSHash Works

The procedure is:

  • Start hash = 0
  • For each character → hash = hash * a + ASCII value
  • After each character → a = a * b

Python Code

def RSHash(string):
    a = 63689
    b = 378551
    hash_value = 0
    
    for ch in string:
        hash_value = hash_value * a + ord(ch)
        a = a * b
        
    return hash_value
